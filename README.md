A program that draws one image, procedurally: a giant red-and-white koi leaps in an arc over a glowing full moon above a starry night sea, with a tiny boat and fisherman below. Pure TypeScript standard library — a hand-rolled rasterizer and PNG encoder, no assets, no downloads. Deterministic: every run produces the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
